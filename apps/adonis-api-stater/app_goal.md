This adonis-api-starter is a hand built port of common patterns from the api app.

The goal is to build a modules based app to scafoold api repositories instantly with all required modules to build common saas apps.

The adonis-api-starter was scaffolded using adonisjs install command.

Use this current brnahc diff to see the hand added files after the scaffold.

The final shadcn like package will scaffold these files into a new adonisjs api-starter project.

only files inside modules will be scaffolded, everything else will be instructions for the user to update.
